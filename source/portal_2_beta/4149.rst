Build 4149 (Mar 18 2010) (AppID 852 v1)

Download link (repack with fixes): https://hl2-beta.ru/index.php?action=downloads;sa=view;down=367

``paintinmap``? Yes (can only use gels in certain maps)

---------------
Notable Changes
---------------

-   Major facelift to the first few chambers
-   Portal gun now has a small refire cooldown
-   Paint colors changed: speed is orange, bounce is blue, stick is purple
-   Portal gun dissappears when grabbing the cube (like retail)
-   New button sounds: activating button is same as retail, deactivating button is this (cut) jarring buzzer
-   New toxic liquid shader used throughout most maps. However, fluid flow not configured and uses default (outside of ``ali_toxicliquid_test``)
-   Paints only works in certain chambers (e.g. paint gun doesn't work in ``devtest_stick``). I think this is controlled by the ``paintinmap`` keyvalue on ``worldspawn``.
-   Too much paint can crash on level change
-   New testing elements: checkpoints (cut), excursion funnel ("tbeam")

-------
ConVars
-------

``portal_transmit_light (0|1)``
    Default: 0. Set to 1 to add a flash light at the portal location

``portal2_square_portals (0|1)``
    Default: 1. Set to 1 to use the big circle portals present in corehub maps

``portal2_portal_width <N>``
    Default: 72. Set square portal size

``Portals_ResizeAll <width> <height>``
    Change portal width/height

``portal2_physgun (0|1)``
    ???

``portalgun_fire_delay <N>``
    Default: 0.5. Portal gun refire cooldown
