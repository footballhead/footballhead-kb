=======================================
Portal 2 Beta Build 4107 (AppID 841 v0)
=======================================

Approx Date: Feb 04 2010

Download link (repack with fixes): https://hl2-beta.ru/index.php?action=downloads;sa=view;down=366

Steam2 DB: https://femtendo.github.io/steam2-catalog/#depot-841

.. warning::
    
    This is an old build of HL2 with unpatched vulnerabities. Only play multiplayer with people that you trust.

.. tip::

    On Windows 11, Smart App Control will block launching any of the ``.bat`` files. It may also interfere with loading any of the ``.dll`` files. To make it work, turn off Smart App Control in Windows settings.

------------
Observations
------------

Oddities:

-   Portal 2 grabbing mechanics
-   Aesthetic closer to retail than :doc:`3916` (broken glass, lighting via projected textures)
-   Portals no longer have particle effects
-   Portals have the colored glow effect that was cut from retail
-   No Wheatley voice lines. Just on-screen text
-   Can fire the portal gun as fast as you can click
-   Portals appear instantaneously on the target surface (no projectile); means no portal peeking

Bugs:

-   Color correction breaks when loading a saved game

    -   Workaround: avoid using save/load system; reload the map instead

    -   Workaround: disable color correction with ``mat_colcorrection_disableentities 1``. However, this does alter the aesthetic.

    .. note::
        
        The Color Correction option in Video settings doesn't do anything

-   Water rendering glitchy (e.g. ``sp_intro_04``)
-   Alt-tabbing when full screen shows garbage for a few frames
-   One glitched frame when walking through world portals

---------------
Useful Commands
---------------

Enable cheats::

    sv_cheats 1

Disable collision and gravity::

    noclip

.. tip::

    You can bind commands to a key with ``bin``. You can also have two or more commands run at the same time with the ``;``. For example::

        bind n "sv_cheats 1;noclip"

Get portal gun::

    give weapon_portalgun

Allow portal gun to shoot both blue and orange portals::

    upgrade_portalgun

Disable color correction (fix trippy color correction bug)::

    mat_colcorrection_disableentities 1

Give paint gun::

    give weapon_paintgun

Allow shooting all paint colors::

    giveallpaintpowers
