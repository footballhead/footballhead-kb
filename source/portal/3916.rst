Steam2 DB: https://femtendo.github.io/steam2-catalog/#depot-852

Requires several fixes:

-   Need to make a ``generic_actor`` with ``target_name`` of ``@glados`` in order for voice lines to play
-   Need fixed ``engine.dll`` for ???
-   Copy all sounds from ``game_sounds_manifest.txt``
-   Copy HL2 scripts folder
-   Extract HL2 assets from ``hl2_misc_dir.vpk``, ``hl2_textures_dir.vpk``, and ``hl2_sound_misc_dir.vpk``
-   Import ``hl2/scripts/game_sounds_manifest.txt`` into ``portal2/scripts/game_sounds_manifest.txt``
-   Add ``hl2`` to ``SearchPaths`` in ``portal2/gameinfo.txt``
-   Run ``snd_rebuildaudiocache``
-   Hammer fix gist.github.com/nikolan123/84be972003eceb3cf4a81caba7857f85

.. code::

    // Save me to portal2/scripts/vscripts/mapspawn.nut
    function fixlines()
    {
        local existing = Entities.FindByName(null, "@glados")
        if (!existing)
        {    
            local ent = Entities.CreateByClassname("generic_actor")
            ent.__KeyValueFromString("targetname", "@glados")
            ent.SetOrigin(Vector(16000, 16000, 16000))
        }
    }

    // game literally crashes without waiting a second lol
    EntFire("worldspawn", "CallScriptFunction", "fixlines", 1.0)

Oddities
--------

-   Old Portal 2 logo
-   Both portal open sounds play when a new portal is shot.
-   ``prop_portal`` doesn't have particle effects
-   Uses Mel character model (blue jump suit)
-   All other assets are Portal retail (cube, button, etc)
-   Portal 2 crosshair behavior (no indication of whether a surface is portalable)
-   Portal "wallhacks" implemented using closed DX8 portal texture
-   "Slowfield" slows down time (e.g. ``devtest``)
-   Early versions of the light bridge, aerial faith plate, lasers (chonky!)
-   Cubes don't have player physics (e.g. on aerial faith plate)
-   ``devtest``: Many portal 2 map additions are connected via world portals
-   No effect for shooting portal projectile at fizzler
-   No portal shoot cooldown
-   Portal shots are instantaneous
-   Portal campaign with minor differences
-   Still Alive campaign without level transitions

Saving
------

The save/load dialog is busted. I wouldn't rely on quicksaves since sometimes the game places then at bad locations.

To save to a file named: ``mysavefile``::

    save mysavefile

To load that file::

    load my save file
